SPOOX AI — локальный AI без API

Что это:
Один HTML-файл с WebLLM. Модель запускается прямо в браузере через WebGPU. API-ключ не нужен.

ВАЖНО:
Для реальной работы WebGPU нужен поддерживаемый браузер и безопасный контекст. Для опубликованного сайта используй HTTPS.
Сам HTML можно открыть для просмотра, но для надёжного запуска лучше разместить его на HTTPS-хостинге.

Первый запуск:
1. Открой сайт по HTTPS.
2. Выбери небольшую модель.
3. Дождись загрузки модели — это может занять сотни МБ.
4. После кэширования модель можно использовать снова без API-ключа, пока браузер не очистит её данные.

В проекте используются CDN для WebLLM и Markdown, а веса модели скачиваются при первом запуске. Поэтому полностью офлайн с нуля этот HTML не является.
